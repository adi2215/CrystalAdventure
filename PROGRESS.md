## 2. Что нажать в Unity (меню **Crystal Adventure → Уровни**)

Уровни и список уровней меняются только этими кнопками (ассеты руками в облаке не правились). Нажимать по порядку; если уровни уже есть, кнопка спросит и перезапишет их на месте.

| Кнопка | Скрипт | Уровни |
|---|---|---|
| Заполнить черновики и добавить в игру | `Editor/DraftLevels` | №16–18 (`LevelFive`, `LevelSeven`, «Змейка» в `LevelEleven`) |
| Создать уровни Winter | `Editor/WinterLevels` | №19–22; при повторном нажатии дописывает новые: Winter10 «Вторая функция» (10, туториал), Winter11 «Обрыв и лесенка» (10), Winter12 «Функция в функции» (9). Уже созданные Winter1–4 не трогает |
| Создать уровни с врагами | `Editor/EnemyLevels` | №23–27: «Синий патруль» (4), «Перекрёсток» (4), «Ледяные пушки» (4), «Корневой змей» (6), «Ледяной ромб» 8×8 (8) |
| Создать уровни с шипами | `Editor/SpikeLevels` | №28–29: «Шипы» (4), «Волна шипов» (7) |
| Создать уровни неба | `Editor/SkyLevels` | №30–33: «Облачный мост» (4), «Попутный ветер» (4), «Телепорт» (4), «Небесный кит» (7) |
| **Расставить уровни по главам** | `Editor/LevelOrder` | Нажать после всех кнопок выше (и после добавления новых уровней). Forest: One…Sixteen (Five, Seven, Eleven — на своих местах; Loop / If после Nine), шипы, Enemy1–2, лесной босс; Winter: Winter1–4, Winter10–12, Enemy3, ледяной босс; Sky: Sky1–3, кит. Номера в таблице выше — до расстановки. |

В скобках — оптимум карточек (проверен перебором программ через ядро, решения с упором в край не считаются).

Другие полезные пункты меню:
- **Crystal Adventure → Ядро → Проверить совпадение со старой системой** — сверка ядра и старых правил по всем уровням (уровни с врагами / шипами / небом проверяются только ядром).
- **Crystal Adventure → Редактор уровней** — инструменты: лёд, плиты, шипы (фаза), облако, ветер (направление), телепорт (пара); «Решить все уровни».

## 3. Главные места в коде

**Ядро** (`Assets/Scripts/CrystalCore/Core/`, без `UnityEngine`):
- `Turn/TurnResolver.cs` — ход: движение (правило касания), эффекты клеток, бой, клетки, планы врагов.
- `Tiles.cs` — лёд, плиты, гриб, шипы, облака, ветер, телепорты, `TileState.Hazard`.
- `Enemies/EnemyBrains.cs` (`ScriptedBrain`), `Enemies/Bosses.cs` (`StormBossBrain`, `SkyBrain`), `Enemies/Snake.cs`.
- `Simulation.cs` — сборка уровня и прогон целиком.

**Мост к игре** (`CrystalCore/Unity/`): `Bridge/CoreRunBridge.cs` (план для старого куба), `Level/LegacyLevelImport.cs` (LevelSt → ядро).

**Старая система + вид:**
- `CharacterCode.cs` — проигрывание плана, смерть-телепорт, ветер / телепорт, сортировка.
- `MovingManager.cs` — `useCrystalCore`, `OnHeroDefeated`.
- `LevelSt.cs` — `LevelEnemy`, новые `SuperBlocks`, `NeedsCore`.
- `World/EnemyLayer.cs`, `EnemyArt.cs`, `SpecialTiles.cs`, `BoardWave.cs`, `SortDepth.cs`, `TileAnim.cs`.
- `UI/SpeedControl.cs`, `SettingsPanel.cs`, `LevelMapMenu.cs`, `GameFont.cs`.
- `Story/StoryDirector.cs`, `StoryLines.cs`, `StoryArt.cs`.

## 4. Проверки (делались после каждой задачи)

- **Тесты ядра** — `CrystalCoreTests/` (вне `Assets`): 138 тестов, 4 падают (см. открытые вопросы, п. 9). Нужен .NET SDK 8 и консольный проект `net8.0`, `LangVersion 9.0`, `EnableDefaultCompileItems=false`, который включает `CrystalCoreTests/**/*.cs`, весь `Assets/Scripts/CrystalCore/**/*.cs` и `Assets/Scripts/LevelSolver.cs`. Сам `.csproj` в репозиторий не попадает.
- **Компиляция runtime-кода без Unity** — справочные сборки `UnityEngine.Modules` + uGUI / TextMeshPro из исходников; 0 ошибок. Как собрать — в `CLAUDE.md`, раздел «Тесты ядра».
- Editor-скрипты проверяются только в тестовом проекте на заглушках (`LevelEditorWindow` — только в Unity).
